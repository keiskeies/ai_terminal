02

配色建议：保留石墨青，收敛为一套 + 明确语义契约

不换品牌色。石墨底 + 青 + 金在终端类产品里辨识度高且耐看（Warp 暗色 IDE 风、Wave 的块式面板同路线）。要做的是：旧色全部退场，每种颜色只承担一种语义。

标签加号贴左

顶栏左组 = [标签…][+]，加号紧随最后一个标签，语义一目了然；右侧只放全局动作（搜索/菜单/AI/SFTP/监控）。

AI / SFTP 正交

AI 右 → SFTP 下，AI 下 → SFTP 右，永远不同轴。任何组合下终端至少保住「整宽或整高」其中一维；窄窗口自动上下堆叠。

AI 底栏原样

功能排（编排/日志/历史/新建/联网/模板）+ 输入框内权限档位、模型、思考胶囊照现有结构，只统一到石墨青 token，不动交互。

导航零占位

Ctrl+K 命令面板 + 顶栏网格菜单 + 覆盖式抽屉。常驻像素占用 = 0，页面浮在工作区上，不打断终端上下文。

宽度与下限

AI 右 / 底 / 悬浮三态 + 专注模式；分栏拖拽设下限：终端不低于 80 列、辅助面板不低于 240px。窄窗口默认底部堆叠。

容器与状态

1px 边框 + 10px 圆角 + 无阴影；3px 语义色条 + 状态胶囊：运行=青、待确认=金、成功=绿、失败=红，SFTP 目录=金、文件=青，全 App 一套词汇。

05

建议落地顺序

  1. P0 · 色彩收敛 — 旧蓝/旧语义色 → tc.* token（约 30 个文件、纯映射替换，低风险）；tagColors 同步换新色系；跑 analyze + 表面阶梯契约测试。收益最大，先做。
  2. P1 · 零占位导航 + 正交双面板 — 顶栏标签加号贴左；Ctrl+K 命令面板、网格菜单、覆盖抽屉；AI 面板右/底/悬浮三态 + 专注模式；SFTP 面板与 AI 正交摆放（右↔下互换），终端最小 80 列保护。AI 底栏功能排与权限/模型/思考胶囊保持现状不动。
  3. P2 · 终端预设扩充 + 浅色复查 — 增加 Catppuccin Mocha / Tokyo Night / Nord（仅暗色，亮色回落默认）；浅色主题逐页复查小字号对比度（≥4.5:1）。
